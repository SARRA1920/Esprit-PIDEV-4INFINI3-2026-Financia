# Pour le code python utiliser les commande suivantes

# Pour preparer l'environnement ML

`py -m venv .venv`

`.venv\Scripts\activate`

`pip install -r requirements.txt`

# Pour preparer l'environnement Face

`py -m venv venv_face`

`venv_face\Scripts\activate`

`pip install -r requirements-face.txt`

# Apres avant de lancer les api:

## Faire la commande

`.venv\Scripts\activate`

Si vous voulez lancer le ML API

## ET

`venv_face\Scripts\activate`

si vous voulez lancer l'API pour Face
