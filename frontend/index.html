À propos du projet

Pourquoi Financia

Une base claire pour la gestion du crédit

Le projet regroupe authentification, modèle de données crédit / remboursement, règles métier (unicité des dossiers en cours) et exposition API pour brancher votre interface.

Parcours client

Connexion puis formulaire de demande avec retour immédiat sur le statut et le score.

Règles métier

Un seul crédit actif (PENDING / APPROVED / ACTIVE) par client jusqu’à clôture ou rejet.

Évolutif

Agents, administration et reporting peuvent s’enrichir étape par étape sur la même base.
